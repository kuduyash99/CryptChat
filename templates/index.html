CryptChat

A Secure Messaging Platform

CryptChat provides a secure username-based messaging platform where registered users can connect and exchange encrypted text messages.

Why CryptChat?

Username-Based Communication
Connect with users using unique usernames instead of sharing phone numbers.
Secure Authentication
User passwords are protected using bcrypt password hashing.
Encrypted Messages
Messages are encrypted using AES-256-GCM before being stored in the database.
Private One-to-One Messaging
Communicate directly with accepted connections through private conversations.

Technologies Used

Frontend
HTML, CSS, JavaScript and Jinja2
Backend
Python and Flask
Database
MySQL
Security
bcrypt and AES-256-GCM

Security Features

CryptChat demonstrates practical security concepts through password hashing, encrypted message storage, authenticated sessions and input validation.

Passwords are protected using bcrypt, while messages are encrypted using AES-256-GCM before database storage.
